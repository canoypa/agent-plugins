---
name: archive
description: 今のセッション、または題名か ID で指したセッションをアーカイブする。
argument-hint: "[セッションの題名か ID]"
disable-model-invocation: true
---

ユーザーがこの skill を呼んだことを、指したセッションをアーカイブすることへの同意として扱い、改めて確認を取らずにアーカイブする。

ARGUMENTS が空なら今のセッションを、あれば ARGUMENTS 全体を一つの題名か ID として、それが指すセッションをアーカイブする。題名で当てたものは、取り違えに気づいて戻せるよう、結果に題名と ID を添える。当たらないか複数当たったときは、候補を見せて聞く。
